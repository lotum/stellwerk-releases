# Stellwerk releases

Disk images of [Stellwerk](https://github.com/lotum/stellwerk) for Mac with the Sparkle feed
(`appcast.xml`) it checks for updates, and the Android APK with its feed (`android.json`). The
release workflow in the (private) source repository publishes here; don't edit by hand.

Download page: [lotum.github.io/stellwerk-releases](https://lotum.github.io/stellwerk-releases).
